# E-Commerce Customer Churn & Revenue Leakage Analysis

## Project Overview
An end-to-end e-commerce analytics project using Python, SQL, and Power BI to analyze customer purchasing behavior, identify inactive customers, understand revenue patterns, and uncover customer retention opportunities.

## Business Problem
E-commerce businesses need to understand:
- Which customers are becoming inactive?
- Which customer segments contribute the most revenue?
- How much historical revenue is associated with inactive customers?
- What opportunities exist to improve customer retention?

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MySQL
- **Power BI:** Data modeling, DAX, interactive dashboards
- **Jupyter Notebook:** Data cleaning and exploratory analysis

## Project Workflow
1. Data loading and cleaning using Python.
2. Exploratory Data Analysis (EDA).
3. RFM analysis and customer segmentation.
4. SQL analysis of revenue, orders, customer behavior, and delivery performance.
5. Power BI data modeling and DAX measures.
6. Dashboard development and business insights.

## Key Business Metrics

| Metric                             | Result |
------------------------------------------------
| Total customers analyzed           | 96,096 |
| Customers inactive for 90+ days    | 87,020 |
| Inactive customer rate             | 90.55% |
| Delivered order revenue            | R$15.42M |
| Delivered orders                   | 96,477 |
| Repeat customer rate               | Approximately 3% |

*Note: Inactivity is defined using a 90-day threshold. It is an indicator of churn risk, not proof of permanent customer loss.*

## Customer Segmentation
Customers were categorized into:
- Champions
- Loyal Customers
- Potential Loyalists
- At Risk
- Hibernating
- Can't Lose Them

## Power BI Dashboards
The report contains two pages:
1. Executive Overview
2. Customer Churn & Revenue Risk

## Business Recommendations
- Develop targeted reactivation campaigns for inactive customers.
- Reward loyal and repeat customers.
- Create personalized offers for potential loyalists.
- Investigate customer experience issues affecting retention.
- Monitor customer inactivity and revenue trends regularly.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.
